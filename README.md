# CRUD-en-Firebase---Tomas--Bermudez---181751

Hola, ¿cómo estas? Soy Tomás Bermúdez. Curso de Desarrollo en React JS. 181751

Para este proyecto hice un CRUD de productos con Firebase, profundizando mas en la seguridad y usando el Rules Playground.

Instrucciones para clonar el repositorio y abrir la página

1 En GitHub, navegue hasta la página principal del repositorio.

2 Encima de la lista de archivos, haz clic en Code.

<img width="379" height="99" alt="image" src="https://github.com/user-attachments/assets/b92e8e22-000e-452e-93ac-c656ace005ab" />

3 Copia la dirección URL del repositorio.

<img width="433" height="322" alt="image" src="https://github.com/user-attachments/assets/107089bf-2c2d-4dce-8ac2-1ac9abd40886" />

5 Cambia el directorio de trabajo actual a la ubicación en donde quieres clonar el directorio.

6 Escriba git clone y pegue la dirección URL que ha copiado antes.

"git clone https://github.com/ttomas4/CRUD-en-Firebase---Tomas--Bermudez---181751.git"

7 Presione Enter para crear el clon local.

Ingresar a la carpeta del proyecto:

"cd CRUD-en-Firebase---Tomas--Bermudez---181751"

Instalar las dependencias:

"npm install"

Ejecutar el proyecto:

"npm run dev"
